# The 11-Stage AI Visibility Lifecycle

**Website Discovery to AI Citations** — and the papers built on it

Bernard Lynch

---

## Overview

The 11-Stage AI Visibility Lifecycle is a framework that maps how AI systems discover, interpret, trust, show and cite websites, and for measuring and reporting AI visibility. Its eleven stages fall into three related phases — AI Comprehension (Stages 1–5), Trust Establishment (Stages 6–8) and Human Visibility (Stages 9–11). Stages 1–2 come first for any page; Stages 3–11 are weighed together, and a domain can be progressing in several at once.

This repository holds the published papers as PDF files, each identical to the file deposited on Zenodo. It is a mirror, not the source: the authoritative version of every paper is its Zenodo record. In the event of any discrepancy, the Zenodo version prevails.
